# USB Мост — приёмники для компьютера

Подключайте выбранные USB-устройства телефона или планшета к компьютеру по сети.
Здесь находятся приёмники Windows/Linux и инструкции. Android-приложение
готовится к первому выпуску в RuStore; публичной ссылки карточки пока нет.

Предварительный выпуск **1.0.13 / vc10017**:

- [Windows x64 — ZIP](https://github.com/varyagnord/usb-most-downloads/releases/download/v1.0.13-vc10017/usb-most-1.0.13-windows-x86_64.zip)
- [Linux x86_64 — tar.gz](https://github.com/varyagnord/usb-most-downloads/releases/download/v1.0.13-vc10017/usb-most-1.0.13-linux-x86_64.tar.gz)
- [Контрольные суммы](https://github.com/varyagnord/usb-most-downloads/releases/download/v1.0.13-vc10017/SHA256SUMS)

Windows: распакуйте ZIP целиком, откройте `USB-Most-Setup.cmd`, подтвердите UAC.
Linux: из терминала графического сеанса запустите `./USB-Most-Setup.sh` и
подтвердите PolicyKit. В браузере откроется локальная страница настройки.
Нажмите «Приложение установлено — подключить» и используйте QR/код в приложении.
Через SSH приложение также может само подготовить приёмник на компьютере.

Для установки нужны права администратора. Linux требует systemd и vhci_hcd;
отсутствующие пакеты ядра устанавливает администратор. Извлечение накопителей
из Android дополнительно требует UDisks2. На Windows LAN-правило ограничено
частными и доменными сетями. Между разными сетями можно использовать Tailscale.
Собственная серверная инфраструктура USB Моста не требуется.

Проверенные границы: Windows11 LTSC2024 build26100.1742 и Ubuntu24.04.5,
эмуляторы Android8/12/14, синтетические USB. В17 исправлено завершение
Linux-помощника: Ctrl+C/SIGTERM удаляют временный файл и сохраняют браузер;
помощник с правами администратора закрывается по времени жизни обычной оболочки.
Это проверено через настоящий PolicyKit и браузер на Ubuntu с готовым приёмником;
первичная графическая установка Linux остаётся отдельной проверкой.

Новый Windows-приёмник прошёл native/kernel и Android SSH/TLS проверки.
Обычный пользователь/UAC/браузер отдельно проверялись на предыдущем бинарном
файле16; графический прогон пересобранного EXE17 отдельно не повторён.
Windows EXE пока без Authenticode, поэтому возможен «Неизвестный издатель»;
драйвер контроллера подписан. HVCI, SmartScreen/MOTW, другие версии ОС и
произвольные физические USB не подтверждены. Изохронные передачи не поддерживаются.

Архивы содержат лицензии и контрольные суммы своих файлов.
[Точные исходники и сборка](https://github.com/varyagnord/usb-most-source/tree/v1.0.13-vc10017).
GPLv3; сторонние компоненты сохраняют собственные лицензии.
APK/AAB, ключи и журналы пользователей здесь не размещаются.
Старые версии доступны в Releases;16 сохранена с предупреждением о Linux GUI.
