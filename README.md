# USB Мост — приёмники компьютера

Предварительный комплект1.0.13/vc10018 для Linux x86_64 и Windows x64. Android-приложение ещё не опубликовано в RuStore.

Телефон или планшет передаёт выбранные USB-устройства компьютеру по сети. Собственный сервер USB Моста не требуется. Для доступной сети предусмотрены прямое TLS-подключение и SSH, для разных сетей можно использовать Tailscale. macOS не поддерживается.

[Скачать приёмники10018](https://github.com/varyagnord/usb-most-downloads/releases/tag/v1.0.13-vc10018) · [Точные исходники GPLv3](https://github.com/varyagnord/usb-most-source/tree/v1.0.13-vc10018).

Windows: распакуйте весь ZIP и откройте USB-Most-Setup.cmd; подтвердите штатный UAC. Linux: распакуйте tar.gz и запустите ./USB-Most-Setup.sh из графического сеанса с PolicyKit. Для сервера без графического сеанса используйте SSH из Android-приложения. Нужны права установки и подходящий USB-стек компьютера. Подробности и лицензии находятся в архивах.

В10018 исправлен запуск Linux-приёмника после TIME_WAIT; первый переход со старого приёмника может занимать около минуты.10017 удержан от подачи из-за этой ошибки, старые теги/архивы сохранены. Источник исправления и полные476 файлов сборки доступны без авторизации.

Проверены собственные VM/эмуляторы: Linux Debian13, Win11 Enterprise LTSC2024 26100.9457 с Secure Boot и существующим подписанным контроллером; Android8/12 core по1124, active storage update по70, Android12 SSH/TLS и два импорта синтетической мыши на обеих ОС. Предыдущие GUI-проверки на других точных бинарных файлах учитываются отдельно; свежая графическая квалификация10018 не заявлена этой упаковкой. Иные версии ОС/HVCI/SELinux, SmartScreen/MOTW и произвольное физическое оборудование не подтверждены. Изохронные передачи не поддерживаются.

У Windows EXE пока нет Authenticode; возможен «Неизвестный издатель». Драйвер контроллера имеет отдельную подпись. APK/AAB, пароли и закрытые ключи здесь не размещаются. Архивы содержат README, GPLv3, сторонние уведомления и SHA256SUMS. Ссылка RuStore появится после публикации карточки.
