# USB Мост — приёмники для компьютера

Подключайте выбранные USB-устройства телефона или планшета к компьютеру по сети.
Здесь размещаются приёмники Windows/Linux и инструкции. Приложение Android
готовится к первому выпуску в RuStore; публичной ссылки карточки пока нет.

Предварительный выпуск **1.0.13 / vc10016**:

- [Windows x64 — ZIP](https://github.com/varyagnord/usb-most-downloads/releases/download/v1.0.13-vc10016/usb-most-1.0.13-windows-x86_64.zip)
- [Linux x86_64 — tar.gz](https://github.com/varyagnord/usb-most-downloads/releases/download/v1.0.13-vc10016/usb-most-1.0.13-linux-x86_64.tar.gz)
- [Контрольные суммы](https://github.com/varyagnord/usb-most-downloads/releases/download/v1.0.13-vc10016/SHA256SUMS)

Windows: распакуйте ZIP целиком, откройте `USB-Most-Setup.cmd` и подтвердите UAC.
Linux с графическим сеансом: распакуйте архив и выполните `./USB-Most-Setup.sh`.
Откроется локальная страница настройки. Нажмите «Приложение установлено —
подключить» и используйте код/QR в приложении на телефоне или планшете.
При SSH приложение Android также может само подготовить приёмник.

Для установки нужны права администратора. Linux требует systemd и модуль
vhci_hcd; отсутствующие пакеты ядра устанавливает администратор. Для извлечения
накопителей из приложения дополнительно нужен UDisks2. На Windows LAN-правило
действует в частных и доменных сетях. Для разных сетей можно использовать Tailscale.

Проверенные границы: Windows11 LTSC2024 build26100.1742 с Secure Boot,
Ubuntu24.04.5 и эмуляторы Android. Windows Memory Integrity/HVCI, все остальные
версии ОС и произвольные физические USB не подтверждены. Windows-оболочка
установки проверена через настоящий UAC/браузер; её EXE пока без Authenticode,
поэтому Windows показывает неизвестного издателя. Драйвер контроллера подписан.
Графический Linux-лаунчер пока проверен по составу/синтаксису; Linux SSH/TLS
проверены на изолированной VM. Изохронные передачи USB не поддерживаются.

Каждый архив содержит лицензионные уведомления и SHA256SUMS своих файлов.
[Точные исходники и сборка](https://github.com/varyagnord/usb-most-source/tree/v1.0.13-vc10016).
