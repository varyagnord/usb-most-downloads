Установка и подключение

Windows
Распакуйте ZIP, запустите USB-Most-Setup.cmd и подтвердите запрос администратора.
Linux
Распакуйте архив и запустите ./USB-Most-Setup.sh в терминале графического сеанса. Нужны systemd и модуль vhci_hcd.
  1. Откройте приёмник на компьютере и создайте QR-код.
  2. На Android выберите подключение по QR-коду и отсканируйте его.
  3. Подключите токен к Android, разрешите доступ и нажмите «Запустить мост».

На сервере без графического сеанса настройте приёмник через SSH из приложения.
