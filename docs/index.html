USB Мост

Подключите USB-токен к телефону или планшету Android и используйте его на своём компьютере с Windows или Linux.

Windows x64

Распакуйте ZIP, запустите USB-Most-Setup.cmd и подтвердите запрос администратора.

Скачать для Windows

Linux x86‑64

Распакуйте архив и запустите ./USB-Most-Setup.sh в терминале графического сеанса. Нужны systemd и модуль vhci_hcd.

Скачать для Linux

Подключение по QR-коду

После установки откройте мастер на компьютере. В Android выберите «Подключение компьютера → QR или код» и отсканируйте QR-код из мастера. Для сервера без графического сеанса настройте приёмник через SSH из приложения.
