Подключить по QR-коду

  1. Откройте приёмник

    Запустите мастер на компьютере и создайте код подключения.

  2. Отсканируйте код

    На Android откройте настройку компьютера и выберите подключение по QR-коду.

  3. Запустите мост

    Подключите токен к Android, разрешите доступ к нему и нажмите «Запустить мост».

Для сервера без графического сеанса настройте приёмник через SSH из приложения.
