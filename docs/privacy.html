USB Мост

Политика конфиденциальности USB Моста

Дата редакции: 23 ноября 2026 года

Разработчик ООО «Альфа-ИТ». Поддержка varyagnord@yandex.ru.

Для чего приложение использует данные

USB Мост пересылает команды USB и ответы подключённого устройства между телефоном или планшетом и выбранным компьютером. Содержание передачи зависит от подключённого устройства и рабочей программы. Приложение использует эти данные для передачи и не отправляет их разработчику.

Где данные находятся

Аккаунт USB Моста не требуется. Аналитических и рекламных SDK нет. Сервер разработчика используется для заказа и подтверждения покупки. USB-данные проходят через память устройства и принимающего компьютера. Адреса, названия сохранённых компьютеров, параметры подключения, доверенные сертификаты и правила USB хранятся на Android-устройстве. Сохранённые пароли, SSH-ключи и данные сопряжения защищены шифрованием с ключом Android Keystore. Системное резервное копирование данных приложения отключено. Приёмник хранит настройки службы, доверие и данные доступа на компьютере в каталоге с ограниченными правами. Удаление компьютера из приложения удаляет локальную запись, но само по себе не отзывает доступ на приёмнике.

Передача по сети

При SSH и защищённом подключении по коду USB-данные передаются по зашифрованному соединению. В обычном режиме USB/IP встроенного шифрования нет; используйте доверенную локальную сеть или защищённый VPN. Адреса сети видны её участникам в объёме, необходимом для соединения. Поиск компьютеров в локальной сети использует сетевое обнаружение. Если пользователь выбирает сторонний VPN, включая Tailscale, его работа регулируется условиями соответствующего сервиса.

Разрешения

Доступ к USB запрашивается у Android для выбранных устройств. Камера нужна только для считывания кода подключения; изображение обрабатывается локально. При импорте SSH-ключа пользователь сам выбирает файл системным диалогом. Уведомление показывает работающий мост и позволяет остановить передачу. Фоновая служба и удержание бодрствования обеспечивают работу соединения.

Покупка и чек

При покупке приложение передаёт серверу разработчика почту для чека и код восстановления. Сервер передаёт CloudPayments почту, сумму и номер заказа. Сервис оплаты обрабатывает платёж на своей странице. Сервер разработчика хранит идентификатор заказа, проверочное значение почты, номер и состояние платежа. Покупка восстанавливается по коду, который хранится на Android. Код, платёжные данные и USB-трафик используются в своих отдельных процессах. USB-команды и ответы устройства не передаются ни серверу покупки, ни CloudPayments. По вопросам об обработке данных покупки пишите в поддержку.

Диагностика

Приложение показывает ограниченный журнал технических событий. Экспорт отчёта запускает пользователь; по умолчанию отчёт не содержит паролей, ключей, сетевых адресов, имён входа и содержимого USB-передач. Сохранённый отчёт остаётся в выбранном пользователем месте. Автоматической отправки отчётов нет. При самостоятельной передаче отчёта в поддержку пользователь определяет получателя. Обращения в поддержку используются для ответа и разбора проблемы. По вопросам доступа к присланным данным или их удаления пишите на varyagnord@yandex.ru.

Удаление и срок хранения

Сохранённые подключения и правила используются до их удаления пользователем или удаления данных приложения. Работающие сеансы прекращаются при остановке моста. Экспортированные файлы и настройки приёмника на компьютере удаляются отдельно пользователем или администратором; удаление APK их не удаляет. Ссылки на исходники и страницы магазина открываются внешним приложением; при переходе действуют правила выбранного сайта или магазина.
